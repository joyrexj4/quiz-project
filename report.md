# Отчёт по практической работе
## «Создание теста командой из трёх студентов в Git»

## 1. Тема и цель

**Тема:** Командная работа в Git. Создание теста из 6 вопросов с использованием веток, Pull Requests и разрешением конфликтов.

**Цель:** Освоить полный цикл командной разработки в Git: создание репозитория, работа в feature-ветках, code review через PR, слияние, ручное разрешение конфликта, оформление отчёта.

## 6. Использованные команды Git

| Команда | Назначение |
|---|---|
| `git clone` | Клонирование удалённого репозитория |
| `git checkout -b` | Создание и переключение на новую ветку |
| `git status` | Просмотр состояния рабочей директории |
| `git add` | Индексация изменений |
| `git commit -m` | Фиксация изменений с сообщением |
| `git push -u origin` | Отправка ветки на GitHub |
| `git pull origin main` | Получение и слияние изменений |
| `git merge` | Слияние веток |
| `git log --oneline --graph --all --decorate` | Просмотр истории коммитов |
| `git branch -d` | Удаление локальной ветки |
| `git tag -a` | Создание аннотированного тега |


## 7. Возникшие трудности и их решение

**Трудность 1:** Конфликт слияния в `README.md` при merge ветки `conflict/b`.
**Решение:** Открыли файл, вручную объединили обе правки, удалили маркеры `<<<<<<<`, `=======`, `>>>>>>>`, выполнили `git add README.md` и `git commit`.

**Трудность 2:** Push отклонялся с ошибкой 403.
**Решение:** Соавторы не приняли приглашение в Collaborators. После принятия приглашения push прошёл успешно.

## 8. Выводы

В ходе работы освоен полный цикл командной разработки в Git:
- создание центрального репозитория и приглашение соавторов;
- параллельная работа в feature-ветках без конфликтов;
- code review через Pull Requests;
- ручное разрешение конфликта слияния;
- синхронизация локальных репозиториев;
- оформление итогового отчёта и версионирование через теги.

Командная работа в Git позволяет безопасно вести параллельную разработку и контролировать качество кода через ревью.
